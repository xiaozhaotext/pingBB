# 网页端与品牌改造说明

## 本轮已实现

- 统一展示名暂定“优选商城”：移动商城浏览器标题、应用名称、导航标题，以及后台浏览器标题和登录页均已替换。正式品牌名由业主确认后再集中替换。
- 新增独立绘制的购物袋图形作为两个 Web 前端的浏览器图标。
- 商城首页在浏览器宽度达到 900px 时展示桌面布局：顶部导航、分类入口、搜索入口、商品区域和账户入口。宽度不足时继续使用移动布局。桌面商品与广告均使用现有 `/home/content` 和推荐商品接口返回的数据；接口无商品时显示空状态，不填充假商品。
- 分类、商品详情、购物车、订单列表和个人中心加入可复用桌面导航，并限制主体宽度。它们保留现有真实 API 与交互。
- 移动首页调整绿色系、卡片层级，并删除“工厂直达”等尚未证实的营销描述。
- 管理后台登录页改为独立排版，去掉原项目蓝色背景和图标；原项目的公众号、教程与体验账号入口已移出面向客户的页面。
- 本地测试构建默认请求 `localhost:8080` 和 `localhost:8085`。上线前必须由部署配置改为正式自有域名和 HTTPS，不能直接使用本地地址。

## 尚未完成

- 桌面 Web 的商品详情、购物车、下单、个人中心目前只是基础宽屏适配，内部组件仍有移动版布局；需要逐页完善并执行宽屏浏览器实际验收，不能宣称完整 PC 商城已交付。
- 平台、商家、消费者三端的完整统一设计系统仍需制作。当前商家工作台尚不能在没有多商家安全模型时开放真实操作。
- 原始 134 条需求的逐条缺口见 [原图134条功能缺口复核.md](原图134条功能缺口复核.md)。已支持状态仅为源码审计，不等于交易闭环验收。
- 当前数据库中的广告、品牌和商品仍是官方示例测试数据。客户演示前需要换成业主授权的自有商品与图片。
