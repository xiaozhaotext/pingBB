# 后台菜单与前端路由对齐（后台桌面 / 系统设置 缺失修复）— 2026-10-15

## 现象

本地后台侧边栏缺少 `后台桌面`、`系统设置` 两个一级功能项（线上有），
并且展开后还缺少 `订单管理 > 筛选 / 订单详情`、`会员 > 会员列表 / 会员操作`、
`财务中心 > 钱包明细管理 / 佣金提现审核`、`系统设置 > 管理首页 / 数据库管理 / 管理员设置` 等二三级菜单。

## 根因

后台侧边栏不是从 `ums_menu` 渲染的，而是**前端路由表**（`mall-admin-web/src/router/index.ts` 的 `asyncRouterMap`）
按当前账号的角色菜单过滤后的结果，过滤规则是「路由 `name` == `ums_menu.name`」：

- 命中 `ums_menu` 的 name → 用菜单的 title / icon / sort / hidden 覆盖路由元数据并保留；
- 没命中且路由不是 hidden → 该路由（连同其子路由）整棵被丢弃。

历史迁移在不同环境给同一批页面写了不同的菜单 name：本地是 `desk` / `sysMgr` / `sysHome` …（33 号 8 分组脚本），
而前端路由名是 `serviceDesktop` / `systemSettings` / `systemManagementHome` …（34/35/41 号脚本在线上补齐）。
名字对不上 → 菜单整棵被过滤掉，于是本地看不到这些入口。线上因为跑过 34/35/41，name 对得上，所以显示正常。

## 修复

1. **新增迁移 `45_admin_menu_route_mirror.sql`**（`mall/document/sql/custom-v10/`）
   把 `ums_menu` 与前端 `asyncRouterMap` 按 name 对齐：补齐缺失菜单、归一标题/图标/排序/隐藏/父子关系、
   给已开通新控制台的角色补齐授权，并隐藏被新控制台取代的旧菜单记录（保留记录与授权，不删除）。
   幂等、可重复执行。一级分组顺序：自选商品管理 > 复购商品管理 > 消费区商品管理 > 订单管理 > 会员 > 财务中心 > 服务中心 > 后台桌面 > 系统设置。
   线上菜单的排序与隐藏以 `GET /admin-api/admin/info` 为基准，保证与线上顺序一致。
2. **新增生成器 `tools/gen_admin_menu_mirror.mjs`**：路由调整后 `node tools/gen_admin_menu_mirror.mjs` 重新生成 SQL，不要手工改 SQL。
3. **修复 `mall-admin-web/src/stores/permission.ts` 白屏崩溃**：`hasPermission` 直接写 `route.meta!.title`，
   而跳转型路由（`orderMgrLegacyList`）没有 `meta`，菜单命中后抛
   `TypeError: Cannot set properties of undefined (setting 'title')`，导致路由初始化失败、页面全白。
   现已改为 `route.meta` 存在时才写入，并修正 icon 判断条件（原来误判 `currMenu.title`）。
   该缺陷在补全菜单后必然触发（本地修复前 100% 复现白屏）。
