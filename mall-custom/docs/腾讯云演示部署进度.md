## 服务器侧尚未执行

用户在网页终端实际运行 `whoami` 后确认为 `root`；先前的 `ubuntu` 回答不是当前登录身份。将本次部署公钥添加至该账号后，`ssh -i .tools/deploy-ssh/id_ed25519 -o BatchMode=yes root@122.51.105.107` 成功。服务器为 Ubuntu 26.04 LTS，约 3.6 GiB 内存、2 GiB swap、根盘 49 GiB 中可用 41 GiB。当前仅 SSH 22 端口监听，UFW inactive；本机探测公网 80 端口不通。`apt-cache policy` 显示 MySQL 8.4.10、Redis 8.0.5、RabbitMQ 4.0.5、Nginx 1.28.3、OpenJDK 17.0.20 均有候选包，但目前均未安装。正在等待用户对系统组件安装的单独批准。服务器尚未初始化独立数据库或启用服务，也未执行公网登录及商品/订单 API 验收。

下一步需要用户在腾讯云网页终端运行 `whoami`，提供用户名，并将本次部署专用公钥加入该用户的 `~/.ssh/authorized_keys`。公钥文件在本机 `.tools/deploy-ssh/id_ed25519.pub`，私钥只保存在本机。确认连接后先盘点服务器，再配置本机绑定的 MySQL/Redis/RabbitMQ、独立测试账号、强随机 JWT 密钥和已标注演示数据。公网登录应先具备 HTTPS；无域名或证书时，仅验证受限访问，不宣称公网登录可安全使用。

## 功能边界

本地仅验证单商家模拟交易。远程演示环境不会启用真实支付、分账、提现、分销奖励或未经测试的商家操作。商家工作台及 A/B 隔离尚未完成，不提供假入口。正式运营仍不具备验收条件。
