# 可直接复用模块清单

本清单的“复用”指保留源码作为二创起点，**不表示已通过本项目的多商家、安全或运行验收**。证据路径相对于 `mall-custom/`，固定 SHA 见《官方源码接管报告》。

| 模块 | 实际源码证据 | 复用范围 | 接入前验证 |
|---|---|---|---|
| 商品分类/品牌 | `mall/mall-admin/src/main/java/com/macro/mall/controller/PmsProductCategoryController.java`、`PmsBrandController.java`；`mall-admin-web/src/views/pms/productCate/index.vue`、`brand/index.vue` | 基础 CRUD、页面结构 | 分类权限、商家可用范围、原图分类文字 |
| 商品 SPU/SKU/属性/图片 | `mall/mall-admin/src/main/java/com/macro/mall/controller/PmsProductController.java`、`PmsSkuStockController.java`；`mall-admin-web/src/views/pms/product`；SQL `pms_product`、`pms_sku_stock` | 通用商品编辑和展示 | 增加归属后所有读写按商家过滤；库存并发改造 |
| 通用搜索/商品展示 | `mall/mall-portal/src/main/java/com/macro/mall/portal/controller/PmsPortalProductController.java`；`mall-app-web/src/pages/product/search.vue`、`list.vue`、`product.vue` | 基础检索、列表、详情交互 | 自选/复购专区与积分规则分离；搜索索引商家范围 |
| Banner/推荐底座 | `mall/mall-portal/src/main/java/com/macro/mall/portal/controller/HomeController.java`；`mall-app-web/src/pages/index/index.vue`；SQL `sms_home_advertise` | 广告和通用推荐呈现 | 自选/复购推荐不得混称已有；运营数据真实化 |
| 通用购物车 UI/API | `mall-app-web/src/pages/cart/cart.vue`、`src/apis/cart.ts`；`mall/mall-portal/src/main/java/com/macro/mall/portal/service/impl/OmsCartItemServiceImpl.java` | 单一购物车增删改选 | 商家分组、跨商家结算及库存校验需改造 |
| 通用订单 UI/API | `mall-app-web/src/pages/order`；`mall/mall-portal/src/main/java/com/macro/mall/portal/controller/OmsPortalOrderController.java` | 订单展示和单商户流程骨架 | 当前支付/详情授权/状态/拆单问题必须先修复 |
| 普通会员注册登录/资料 | `mall/mall-portal/src/main/java/com/macro/mall/portal/controller/UmsMemberController.java`；`mall-app-web/src/pages/public/login.vue`、`register.vue`、`user/user.vue` | 普通消费者账号路径 | 会话撤销、禁用、审计、个人数据对象授权实测 |
| 收藏、足迹、地址 | `mall-app-web/src/pages/user/productCollection.vue`、`readHistory.vue`、`address/address.vue`；portal 同名 Controller | 现有通用用户功能 | 数据归属和隐私测试 |
| 促销内容底座 | `mall/mall-admin/src/main/java/com/macro/mall/controller/SmsCouponController.java`、`SmsHomeAdvertiseController.java`；`mall-admin-web/src/views/sms` | 优惠券、广告、通用运营页面 | 商家适用范围、规则冲突和预算核验 |
| 平台管理员 RBAC | `mall/mall-admin/src/main/java/com/macro/mall/controller/UmsAdminController.java`、`UmsRoleController.java`、`UmsMenuController.java`；`mall/mall-security/src/main/java/com/macro/mall/security/component/DynamicAuthorizationManager.java`；`mall-admin-web/src/views/ums` | 平台管理员、角色、资源和菜单基础代码 | 商家员工身份、行级隔离、高风险操作审计须新增 |

`mall-search` 可作为搜索技术底座，但当前本机无 Elasticsearch，索引与 API 尚未运行验收。支付 SDK、现有积分抵扣及静态后台图表**不列为可直接启用模块**。
