# 后台管理员登录失败与密码重置（2026-10-13）

## 现象

后台入口 `https://122.51.105.107/admin/` 用 `admin` / `admin123` 登录失败，页面提示「密码不正确」。

实测接口，证据可复现：

| 请求 | 结果 |
| --- | --- |
| `POST /admin-api/admin/login`，`username=admin`，`password=admin123` | `{"code":500,"message":"密码不正确"}` |
| 同上，密码换 `macro123`/`123456`/`Admin@123`/`admin@123456`/`mall123` | 均为 `密码不正确` |
| 同上，用户名换 `test`/`root` | `{"code":404,"message":"用户名或密码错误"}` |

`404 用户名或密码错误` 表示用户名不存在，`500 密码不正确` 表示用户名存在但 BCrypt 校验不通过。
因此结论是：**只有 `admin` 这一个平台管理员存在，且它在数据库中的密码哈希已被改动，
不再对应 `admin123`**（`deploy/init-db/01_mall.sql` 里的上游种子哈希对应 `macro123`，也已不匹配）。

## 为什么不能远程重置

本次逐一核对，均不可行：

- 服务器公网只监听 **22**（SSH，仅 `publickey`）与 **443**；`80`、`3306`、`6379`、`8080`、`8085` 等均关闭，无法直连数据库。
- 本机已无部署私钥：`.tools/` 目录（含 `.tools/deploy-ssh/id_ed25519`）不在磁盘上，`~/.ssh` 只有 `known_hosts`，
  故 `ssh root@122.51.105.107` 直接返回 `Permission denied (publickey)`。
- 后台没有免登录重置入口：`POST /admin-api/admin/register` → 404（`MALL_ADMIN_REGISTRATION_ENABLED=false`），
  `GET /admin-api/admin/updatePassword` → `401 暂未登录或token已经过期`，
  `secure.ignored.urls` 白名单也只有 `/admin/login`。

所以重置必须在服务器本机执行（腾讯云控制台的网页终端 / VNC 即可）。
`deploy/demo/reset-admin-password.sh` 就绪，可在本机执行，无需 SSH 私钥。

## 重置步骤

在服务器上以 `root` 执行（腾讯云控制台网页终端）：

```bash
# 方式一：直接用仓库里的脚本（默认重置为演示密码 admin123）
cd /root   # 或脚本所在目录
bash reset-admin-password.sh
```

```bash
# 方式二：三行命令手动执行，效果相同
db_password="$(sed -n 's/^SPRING_DATASOURCE_PASSWORD=//p' /etc/mall-demo/db-password.env)"
hash='$2a$10$bd7hUHHwJzt3CYN5W3/.UOQweHzZZZMzi3s0Bsrtf9IUkl2SYvP7y'   # bcrypt(admin123)
MYSQL_PWD="$db_password" mysql -umall_demo -h127.0.0.1 mall_demo -e "UPDATE ums_admin SET password='$hash', status=1 WHERE username='admin'; SELECT username, status FROM ums_admin WHERE username='admin';"
```

要点：

- 数据库 `mall_demo`、库账号 `mall_demo@127.0.0.1`，口令在 `/etc/mall-demo/db-password.env`（`600`，仅 root 可读）；
  该账号有 `mall_demo.*` 的 `SELECT/INSERT/UPDATE/DELETE`，足够改密码，不需要 MySQL `root` 口令。
- 只改 `password`、`status` 两列，不动 `id=3` 及原角色关联，也不影响其它管理员和业务数据。
- 管理员登录每次都实时读 `ums_admin` 校验，不依赖 Redis 缓存，**改完无需重启服务、无需清缓存**。
- 上述 `hash` 用 `MYSQL_PWD` 传口令，避免口令出现在 `ps` 输出里；脚本也不会回显明文密码。

## 重置后验证

```bash
curl -sk https://127.0.0.1/admin-api/admin/login -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'
```

期望 `code:200` 且返回 `token`；再用浏览器打开 `https://122.51.105.107/admin/` 登录后台确认。
