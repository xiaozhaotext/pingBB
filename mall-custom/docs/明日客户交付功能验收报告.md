## 一、本轮交付内容（代码已实现）

### 1. 数据库迁移契约（独立、可回滚）
路径：`mall/document/sql/custom-v10/`（01–09 + rollback_all.sql + README.md）
覆盖：会员身份、邀请码与推荐关系、双积分钱包、合伙人、联创、收益与提现、系统设置与日志、每日分红池、商城体验。
每张新表均带 `simulate_flag=1`（资金类），外键指向 `ums_member(id)`，含乐观锁 `version` 与幂等键。

### 2. P0 后端核心（mall-portal）—— 真实业务闭环
| 模块 | 类 | 关键能力 |
|---|---|---|
| 会员身份 | MemberIdentityController / Service/Impl | 查询身份、后台变更（写审计） |
| 邀请码与推荐 | InvitationController / Service/Impl + Mapper | 一人一码、防自改、防重复绑定、防循环（`bind_path` 回溯）、审计 |
| 双积分钱包 | PointsWalletController / Service/Impl + Mapper | 商品/复购双账户、**事务一致 + 幂等(idempotency_key) + 乐观锁 + 防负余额 + 流水可追溯** |
| 合伙人（模拟） | PartnerController / Service/Impl + Mapper | 方案展示、模拟下单、模拟支付→身份升级+双积分赠送（事务+幂等） |
| 联创（模拟） | CofounderController / Service/Impl + Mapper | 方案展示、模拟下单、模拟支付→身份升级+联创积分赠送 |
| 收益与提现（模拟） | Earnings/Withdraw Controller / Service/Impl + Mapper | 收益账户、流水、模拟发放、**提现手续费0.6%(待审批)、状态流转、无真实打款** |
| 每日分红池（模拟） | DividendPoolController / Service/Impl + Mapper | **多劳多得：ratio=个人贡献/总贡献，严禁平均/写死/随机；退款负贡献冲回；计算幂等可复算(calc_batch)** |

### 3. P0 前端（mall-app-web，uni-app/Vue3）
新增页面（`src/pages/member/`）：`center` `invitation` `partner` `cofounder` `earnings` `dividend`；
API 模块 `src/apis/member.ts`；已在 `pages.json` 注册路由。
界面统一标注「模拟」「不涉及真实资金」。

## 三、模拟 vs 真实（合规边界）

- **真实**：身份升级、邀请关系、双积分发放/扣减、推荐防循环、分红比例计算引擎、所有审计日志。
- **模拟（明确标注，不接入真实资金）**：合伙人 3999、联创 10000 的支付、收益金额、提现打款、分红入账。
- **待客户确认**：分红资金来源、结算周期、提现手续费（0.6%）、合伙人/联创奖励规则草案、短信/微信服务（保持"未连接"状态，不伪造接入）。
