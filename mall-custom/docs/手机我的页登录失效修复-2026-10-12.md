# 手机“我的”页登录失效处理

用户反馈打开 /#/pages/user/user 持续提示错误，仅提供网址，尚未提供错误文字或截图。不能确认该缺陷是其手机的唯一原因。

服务器真实测试账号的 /sso/info、身份、两类积分、邀请关系、优惠券六个接口均返回 HTTP200 与业务200。失效测试 Token 请求积分接口返回 HTTP200、业务401。服务器仅监听 HTTP80，未配置 HTTPS443。

发现：多个并发请求业务401会重复退出与 navigateTo；HTTP401未进入清理会话分支；我的页在并发请求已退出后还继续发起身份和优惠券请求。修复如下：

- src/utils/http.ts：统一处理 HTTP401 和业务401，一次失效只跳登录一次，已在登录页不再跳；成功登录重置守卫；旧 Token 的迟到响应不能退出新账号。
- src/pages/user/user.vue：并发请求后若已退出立即终止后续加载；优惠券空列表正常显示0。

H5 实际构建通过，mobile-session-build-2026-10-12.log。

`node .tools/mobile-session-test.cjs` 使用真实 HTTP 模块经 TypeScript 转译，mock uni 平台和返回结果验证四项：并发失效只跳一次、HTTP401与重新登录后守卫重置、迟到响应保护新会话、已在登录页不跳。4 PASS，0 FAIL，mobile-session-test-2026-10-12.log。这是会话处理单元测试，不是用户手机实机验收。
