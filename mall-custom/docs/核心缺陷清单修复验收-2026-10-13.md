## 四、新阻塞：收藏 / 足迹 / 品牌关注「登录后 30 秒超时」

- 本地带登录态实测（member `test/123456`）：

```
 0.111s HTTP 200 /member/productCollection/list  total=1 rows=1
 0.083s HTTP 200 /member/readHistory/list        total=0 rows=0
 0.064s HTTP 200 /member/attention/list          total=0 rows=0
```

- 前端 `utils/http.ts` 超时为 10 秒，三个页面 `onLoad` 各只发一个请求且都有 `catch`，不存在叠加请求。
- 结论：**本地无法复现**。该现象高度指向「用户浏览器访问的是线上旧包 / 会话 token 未随请求发出」。部署本轮代码后再复验即可。
