## 八、需合规审批的资金 / 奖励规则（未批准前严禁启用真实动作）

- 积分与人民币**不得直接等同**（除非业务明确且获批）。
- 分红 / 分享奖励 / 收益**不得启用真实入账或自动发放**。
- 提现**不得真实打款、银行转账或第三方付款**；所有金额必须明确标识为"模拟"，不得展示为真实可提现资产。
- 短信 / 微信等外部服务仅保留配置入口与"未连接"状态，**不得伪造接入成功**。
- 分红池计算任务必须幂等、可追溯、可复算；不得使用随机贡献值或写死收益冒充真实业务数据。
