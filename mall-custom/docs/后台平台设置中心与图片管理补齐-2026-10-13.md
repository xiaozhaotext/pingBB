## 二、代码变更

### 后端 mall-admin（新增）
- `mall/mall-admin/src/main/java/com/macro/mall/service/SystemSettingService.java`
  设置中心核心：白名单键注册表（只有注册键可通过接口写入）、逐键校验、敏感项脱敏、`sys_content` 合规文本读写、
  后台权限缓存清理、IP 访问规则解析（支持单 IP 与 CIDR，回环地址始终放行）、审计写入 `sys_audit_log`（表缺失时降级并记录日志）。
- `mall/mall-admin/src/main/java/com/macro/mall/controller/SystemSettingController.java`
  `/p0/system-settings`：分组设置读取、设置写入、缓存清理、合规文本读写、图片资产统计。
  所有写操作都经过 `P0AdminAccess.requireAuthorized`（角色 5）并写审计。
- `mall/mall-admin/src/main/java/com/macro/mall/config/AdminIpAccessFilter.java`
  后台 IP 访问过滤；规则最多 10 秒重新读取一次，命中拒绝返回 403 JSON。
  仅当直连对端是回环地址（即本机 Nginx 反代）时才信任 `X-Real-IP` / `X-Forwarded-For`，避免伪造来源绕过限制。
- `mall/mall-admin/src/main/java/com/macro/mall/config/AdminIpAccessConfig.java`
  以 `FilterRegistrationBean` 注册过滤器，order 在 Spring Security 之前。

### 后端 mall-portal（改动）
- `mall/mall-portal/src/main/java/com/macro/mall/portal/controller/HomeController.java`
  新增 `GET /home/siteInfo`，仅暴露 `company.*`、`watermark.*` 与隐私政策/用户协议文本。
  支付、短信、小程序密钥一律不返回给前台；表未迁移时返回空区块而不是让首页整体失败。

### SQL（新增）
- `mall/mall/document/sql/custom-v10/22_admin_settings_center.sql`
  创建 `sys_content`；以 `INSERT IGNORE` 注入 18 个设置键（可重复执行、不覆盖已有改动）；
  新增 `p0SystemSettings`、`p0Images` 两个菜单并授权角色 5。写法沿用 `20_operations_permissions.sql` 的既有约定。

### 后台前端 mall-admin-web
- 新增 `src/views/p0/SystemSettings.vue`（公司信息/水印/小程序/IP 访问/服务内容/缓存维护六个标签页）
- 新增 `src/views/p0/ImageManager.vue`（列表/图文/文件夹/图片统计；统计包含非 HTTPS 图片数量）
- 新增 `src/components/LockScreen/index.vue`，配合 `src/stores/app.ts` 的 `locked/lock/unlock` 与 `src/views/layout/Layout.vue` 的遮罩
- `src/views/layout/components/Navbar.vue` 增加「系统锁屏」「清除缓存」
- `src/router/index.ts` 注册 `p0/system`、`p0/images` 两个路由（显示与否由菜单授权决定）

### 移动端 mall-app-web
- `src/apis/home.ts` 新增 `getSiteInfoAPI()`
- `src/pages.json` 与 `src/pages/public/privacy.vue` 新增隐私政策页（`?type=agreement` 切换用户协议）
- `src/pages/user/user.vue` 在「我的服务」新增隐私政策入口
- 新增 `src/components/WatermarkOverlay.vue`，并在 `src/pages/product/product.vue` 商品图轮播内按后台配置叠加水印（默认关闭）

## 四、未完成与风险说明

- 本机没有 MySQL 与 Docker，图片资产与设置读写**未在真实数据库执行**，只做了语法解析与字段/类型静态核对。
- 本轮改动**尚未发布到 122.51.105.107**：该服务器公网仅 22（只读密钥）与 443 可达，本机没有部署私钥，无法远程操作。
- 上线前必须先执行 `22_admin_settings_center.sql`；未执行时后台会提示未检测到 `sys_content` 表，设置项也不会生效。
- `document/sql/custom-v10/07_system_log.sql` 会 `DROP TABLE` 重建 `sys_config`/`sys_audit_log`，生产库**不要**重复执行该文件。
- 资金、分销、提现相关（合伙人/联创/提现等 23 条 BLOCKED）按仓库既有约定保持关闭，本轮未实现。
- 服务器后台 `admin/admin123` 登录失败是数据库密码哈希被改动所致，与本轮改动无关，
  处置方案见 `docs/后台管理员登录失败与密码重置-2026-10-13.md`。
