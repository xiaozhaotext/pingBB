# 品牌区、复购区、消费区交付验收

## 本次行为

根据用户视频与截图，首页改为上方一张品牌区大卡、下方并排复购区与消费区；保留旅游配色与山水插画。

- 品牌区沿用自选区 `PICK`，页面和导航名称显示“品牌区”，原有专区商品归属不变。
- 复购区沿用 `REBUY`。
- 消费区是明确标注“预留／暂未开放”的独立页面和后台空状态，不接受商品分配与交易。
- 首页“为你优选”调用真实 `/product/zone/REBUY`，只显示复购区已上架、未删除的商品；商品卡进入商品详情并携带 `zone=REBUY`。暂无商品时显示空状态，加载失败时可重试。
- 后台“商品 → 专区商品管理”新增品牌区、复购区、消费区三个标签页。可搜索现有商品、查看已分配商品、加入专区、保存排序、移出专区；只移除归属，不删除商品。

## 服务端与数据

- `ProductZoneAdminController`：`GET /p0/zones/{zone}/products`、`POST /p0/zones/{zone}/products`、`DELETE /p0/zones/{zone}/products/{productId}`。
- 沿用已有 `pms_product_zone` 的唯一键与外键，没有新增消费区结算规则或修改交易金额。
- 后端先通过 `P0AdminAccess` 验证平台角色，并叠加原 mall `/p0/**` 的资源 RBAC；不使用消费者接口管理专区。
- 更新在事务中锁定商品记录，重复提交不重复写入或审计；变更记录写入 `sys_audit_log`。
- 增量 SQL `mall/document/sql/custom-product-zones-admin-menu.sql` 只增加菜单及角色 5 的菜单授权。在演示库重复执行两次成功，没有清空业务数据。

## 操作与恢复

1. 打开 `http://122.51.105.107/admin/`，使用已重置的演示管理员登录。
2. 进入“商品 → 专区商品管理”，选择品牌区或复购区。
3. 搜索商品，点击“加入专区”；可调整排序并保存。
4. 打开 `http://122.51.105.107/`，复购区在售商品会出现在“为你优选”。
5. 消费区仍为空白预留，不开放交易。
