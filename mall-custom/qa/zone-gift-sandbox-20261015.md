# 购买赠分与沙盒演示

普通商品只有订单行专区 PICK 才允许购买赠商品积分；REBUY、CONSUME、空专区、未知专区均不赠。商品属于多个区时以本次订单行专区为准。生成订单时清零非自选区赠分，支付履约时再次过滤（覆盖旧待支付订单）。已发出的历史积分不回收。旅游权益购买仍走独立 MembershipVerifiedPaymentHandler，双积分和身份规则不变。

购物车底栏仅显示已选数量、结算明细开关、去结算；明细默认收起，点击 V 展开有高度限制的滚动面板。金额为商品小计，实际抵扣以确认页后端预览为准。

## 沙盒

构建：mall-app-web 中 npm run build:h5:sandbox；对应 /sandbox/，API 固定 /sandbox/portal。生产构建不得启用 VITE_USE_MOCK_PAYMENT。后端 mall.payment.mock.enabled=true 仅用于指向独立 mall_demo_sandbox 数据库、独立 Redis/Mongo/RabbitMQ 的沙盒实例。生产接口维持模拟支付关闭。

演示：使用专用测试账号，查看初始双积分；自选区测试商品购买并确认模拟支付，查看商品积分增加和订单流水；复购区全现金或积分加现金购买，不赠分；消费区商品积分购买，只扣不赠。相同支付重复确认不得重复发积分。旅游权益从商品详情专用权益入口购买，验证原有双积分到账。

限制：不代表实际微信/支付宝渠道验证，不验收已付款混合来源售后退款。
